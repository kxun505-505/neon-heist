# 霓虹转环 NEON LOOPS · 试玩版

圆环解扣类解谜的网页试玩，5 关，日落海岸霓虹画风。玩法对标 Rotate Rings（`com.nebula.rotaterings`），美术、音效、关卡全部原创。

## 运行
- 直接双击 `index.html` 即可（没有构建步骤，没有外部依赖）。
- 手机上试玩：`python3 -m http.server 8000`，手机和电脑连同一个 Wi-Fi，打开 `http://<电脑IP>:8000`。
- URL 参数：`?unlock` 解锁全部关卡，`?level=3` 直接进入第 3 关。

## 玩法
- 按住环拖动旋转；松手时缺口靠近两环相扣的交点会自动吸附对正。快速甩动有惯性。
- 两环相扣处只要落在任一环的缺口里，这对扣就打开。
- 一个环和所有相扣的环都解开时自动脱出，脱出可以连锁。全部脱出即过关。
- 锁：环中心显示挂锁，挂锁颜色就是钥匙环的颜色。钥匙环脱出前不能转。
- 联动：黄色连杆连着的两个环反向同步转动；任一方被锁，整组转不动。
- 固定环：银色带螺栓，不能转，只能靠别的环解开。
- 有撤销、重来和提示（提示由求解器实时算出下一步最优操作）。没有计时，三星按步数评定。

| 关卡 | 新机制 | 最少步数 |
|---|---|---|
| 1 海滨大道 | 旋转、对缺口 | 1 |
| 2 日落长链 | 一个环扣多个环 | 2 |
| 3 棕榈三角 | 锁 | 3 |
| 4 霓虹齿轮 | 联动 | 4 |
| 5 午夜霓虹 | 固定环、多重相扣 | 8 |

## 目录
- `src/core.js` 规则和求解器（与渲染无关）
- `src/levels.js` 关卡数据
- `src/main.js` 输入、动画、渲染
- `src/bg.js` 程序绘制的背景，`src/audio.js` 合成音效
- `tools/verify.sh` 用本机 Chrome 无头模式跑检查：
  - `tools/verify.sh` 每关最少步数、开局是否已有环可脱出
  - `tools/verify.sh design.html` 关卡草稿试验台
  - `BUDGET=600000 tools/verify.sh playtest.html` 用合成触摸事件把 5 关自动玩一遍
